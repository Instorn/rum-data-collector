# Privacy Policy — "RUM Monitor — Web App Performance" browser extension

[Русская версия](privacy-policy-ru.html)

Effective date: 30.10.2026
Publisher: Yuriy Sushkov
Privacy contact: polentmail@gmail.com

## 1. Purpose

The extension is a Real User Monitoring (RUM) tool for web application performance. It
measures page load speed, interface responsiveness, freezes and errors in web
applications so that developers can find and fix the causes of slow performance.

It is configured by an administrator through browser policies (managed storage).

## 2. Where the extension works

Data is collected **only on websites from the list set by the administrator**. On all
other websites the extension disables itself immediately and collects, stores and
transmits nothing.

If the administrator has not set such a list (for example, the extension is installed
without a policy), the extension collects no data on any website.

## 3. Data collected

On administrator-listed websites only:

- **Performance metrics:** page and resource load timing, Web Vitals (LCP, CLS, INP and
  others), long tasks, response time to user actions, duration of the page's network
  requests.
- **Page and network request URLs** of these websites. Before storage, identifiers are
  removed: numeric IDs, GUIDs and ID-like query parameters are replaced with masks.
- **Interface actions:** the fact of a click, the element tag and CSS selector, the link
  address (with identifiers masked). Element text is not collected.
- **Page freezes** and interface anomalies.
- **Workstation details:** computer label, organization, site and service notes if set by
  the administrator in the browser policy (otherwise a random identifier generated by the
  extension); browser version and time zone.

## 4. Data NOT collected

- keystrokes or values entered into form fields;
- passwords, authentication data, cookies;
- page content, including tab titles and the text of clicked elements;
- browsing history on websites outside the administrator's list;
- device geolocation;
- device characteristics: screen resolution, CPU, memory;
- any data in a browser where the administrator has not set a website list (see section 2).

## 5. Storage and sharing

- Collected data is stored **locally in the browser** on this computer
  (`chrome.storage.local`). Storage is size-limited: older records are replaced
  automatically.
- The extension **does not transmit collected data to any server** — not to the
  publisher, Google or any third party.
- Data leaves the browser only as **export files** (CSV, JSON, ZIP) saved to this
  computer's Downloads folder, either manually from the extension popup or on a schedule
  set by the administrator. Further handling of these files is up to the user or the
  administrator who configured the extension.
- One service setting — the extension's on/off flag — is stored in `chrome.storage.sync`
  and may be synchronized through the user's Google account if browser sync is enabled.
  No collected data is stored there.
- Data is not sold and is not used for advertising, creditworthiness assessment or any
  purpose unrelated to the extension's purpose (section 1).

## 6. Retention and deletion

- Data is kept until it is replaced by newer records, cleared, or the extension is
  removed.
- If the administrator enables cleanup after scheduled export, records older than 1 hour
  are deleted after a successful export.
- All collected data can be deleted with the clear button in the extension popup.
- When the extension is removed, the browser deletes all its data.

## 7. User rights

The extension is installed and configured by an administrator. For questions about the
data, its export or deletion, contact that administrator or the contact listed at the
top of this document.

## 8. Chrome Web Store compliance

The use of information complies with the Chrome Web Store User Data Policy, including the
Limited Use requirements.

## 9. Changes

If the set of collected data or the way it is transmitted changes, this policy will be
updated before the corresponding extension version is released. The effective date is
shown at the top of this document.
