# Политика конфиденциальности расширения «RUM Monitor — скорость веб-приложений»

[English version](privacy-policy.html)

Дата вступления в силу: 30.10.2026
Издатель: Yuriy Sushkov
Контакт по вопросам конфиденциальности: polentmail@gmail.com

## 1. Назначение расширения

Расширение — инструмент мониторинга производительности веб-приложений
(Real User Monitoring, RUM). Оно измеряет скорость загрузки страниц, время отклика
интерфейса, зависания и ошибки в веб-приложениях, чтобы разработчики могли находить и
устранять причины медленной работы.

Расширение настраивает администратор через политики браузера (managed storage).

## 2. На каких сайтах работает расширение

Данные собираются **только на сайтах из списка, который задал администратор**. На всех
остальных сайтах расширение сразу выключает себя и ничего не собирает, не хранит и не
передаёт.

Если администратор список не задал (например, расширение установлено без политики),
расширение не собирает данные ни на одном сайте.

## 3. Какие данные собираются

На сайтах из списка администратора:

- **Показатели производительности:** время загрузки страницы и её элементов, Web Vitals
  (LCP, CLS, INP и др.), длительные задачи, время отклика на действия, длительность
  сетевых запросов страницы.
- **Адреса страниц и сетевых запросов** этих сайтов. Перед сохранением из адреса
  удаляются идентификаторы: числовые ID, GUID и параметры запроса, похожие на ID,
  заменяются масками.
- **Действия в интерфейсе:** факт клика, тег и CSS-селектор элемента, адрес ссылки (с маской
  идентификаторов). Текст элементов не собирается.
- **Зависания страниц** и аномалии работы интерфейса.
- **Сведения о рабочем месте:** имя компьютера, организация, площадка и служебные
  пометки, если их задал администратор в политике браузера (иначе — случайный
  идентификатор, который создаёт расширение); версия браузера и часовой пояс.

## 4. Какие данные НЕ собираются

- нажатия клавиш и значения, введённые в поля форм;
- пароли, данные авторизации, cookies;
- содержимое страниц, в том числе заголовки и текст элементов, по которым кликает
  пользователь;
- история посещения сайтов вне списка администратора;
- геолокация устройства;
- характеристики устройства: разрешение экрана, процессор, память;
- любые данные в браузере, где администратор не задал список сайтов (см. п. 2).

## 5. Где хранятся данные и кому передаются

- Собранные данные хранятся **локально в браузере** на этом компьютере
  (`chrome.storage.local`). Объём хранилища ограничен: старые записи автоматически
  вытесняются новыми.
- Расширение **не передаёт собранные данные на серверы** — ни издателю, ни Google, ни
  третьим лицам.
- Данные покидают браузер только в виде **файлов выгрузки** (CSV, JSON, ZIP), которые
  сохраняются в папку загрузок этого компьютера вручную из окна расширения или по
  расписанию, заданному администратором. Дальнейшее обращение с этими файлами
  определяет пользователь или администратор, который настроил расширение.
- Одна служебная настройка — флаг включения расширения — хранится в `chrome.storage.sync`
  и при включённой синхронизации браузера может синхронизироваться через аккаунт Google.
  Собранные данные туда не попадают.
- Данные не продаются, не используются для рекламы, оценки кредитоспособности или
  целей, не связанных с назначением расширения (п. 1).

## 6. Сколько хранятся данные и как их удалить

- Данные хранятся до вытеснения новыми записями, до очистки или до удаления расширения.
- Если администратор включил очистку после выгрузки по расписанию, после успешной
  выгрузки удаляются записи старше 1 часа.
- Все собранные данные можно удалить кнопкой очистки в окне расширения.
- При удалении расширения браузер удаляет все его данные.

## 7. Права пользователя

Расширение устанавливает и настраивает администратор. С вопросами о данных, их выгрузке
и удалении обращайтесь к этому администратору или по контакту, указанному в начале
документа.

## 8. Соответствие политике Chrome Web Store

Использование данных соответствует Политике в отношении пользовательских данных
Chrome Web Store (Chrome Web Store User Data Policy), включая требования Limited Use.

## 9. Изменения политики

При изменении состава собираемых данных или способа их передачи эта политика будет
обновлена до выхода соответствующей версии расширения. Дата вступления в силу указана в
начале документа.
